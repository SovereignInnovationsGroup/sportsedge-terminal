# Images Directory

## Required Image
Place your futuristic soccer background image here as:
- `hero-soccer-futuristic.png` (recommended size: 1920x1080 or larger)

## Image Requirements
- **Format**: JPG, PNG, or WebP
- **Size**: At least 1920x1080px for desktop
- **Quality**: High resolution for crisp display
- **Theme**: Futuristic soccer/sports related
- **File size**: Optimize for web (aim for under 500KB)

## Image Sources
You can get suitable images from:
- Unsplash.com (search "futuristic soccer" or "digital sports")
- Pexels.com 
- Adobe Stock
- Create custom image with AI tools

## Current Implementation
The image is referenced in `App.tsx` as:
```javascript
backgroundImage: `url('/images/hero-soccer-futuristic.png')`
```

Update the filename in App.tsx if you use a different name.
